# Retro Room Demo (Godot 4.3+)

Демо для проверки шейдера `shaders/retro_post.gdshader`.

## Запуск
1. Распакуйте архив.
2. Godot → Import → выберите `project.godot`.
3. Нажмите F5.

## Сцены
- **Комната** (`main.tscn`): статичный кадр, point & click, клавиши для настройки шейдера.
- **Улица** (`night_street.tscn`): ночная дождливая улица с параллаксом, по которой ходит полицейский.

### Меню (пауза)
Меню — это пауза поверх текущей сцены (`scripts/pause_menu.gd`, подключён как autoload `PauseMenu`).
- **Esc** — открыть/закрыть меню. Пока оно открыто, сцена затемнена и стоит на паузе.
- Кнопки: **Комната**, **Улица**, **Выход**.
- **↑ / ↓** (или W/S) — выбор, **Enter / Space** — выполнить; работает и мышью.
- При запуске игры меню открыто поверх первой сцены.

### Улица
Сцена начинается у служебной машины: патрульный выходит из неё на тротуар
и отходит на пару шагов (около 3 секунд), после чего управление переходит игроку.
- **A / D** (или ← / →) — идти
- Клик по значку (лупа, глаз) — подсказка внизу
- **H** — скрыть список клавиш

## Управление в комнате
- **Tab** — включить/выключить эффект (сравнить «до/после»)
- **1 / 2** — меньше/больше уровней цвета (постеризация)
- **3 / 4** — сила дизеринга
- **5** — переключить внутреннее разрешение (160×120 → 480×360)
- **6 / 7** — сила синего тона
- **8 / 9** — зерно (по умолчанию выключено)
- **0** — палитра: зелёный / синий / тёплый
- **Q / W** — сетка между пикселями
- **A / S** — резкость пикселей
- **D** — пыль вкл/выкл
- **L** — свет (лампа, потолок, картина) вкл/выкл
- **Z / X** — сила свечения (bloom)
- **H** — скрыть подсказку

Клавиши работают в любой раскладке.
- Клик по иконкам (лупа, глаз) показывает субтитр

## Как устроена сцена
```
Main (Node2D)
├─ Background     — фон (assets/background.png, 960×720)
├─ Lights         — свет: LampLight, CeilingLight (иногда моргает), PaintingGlow
├─ Dust           — пыль: AirDust (по всей комнате), LampDust (у лампы), CeilingDust (под светильником)
├─ PostFX (CanvasLayer 1) → Effect: ColorRect с шейдером
└─ UI (CanvasLayer 2)     — иконки, субтитры, подсказка (поверх эффекта, чёткие)
```
Всё, что лежит ниже `PostFX`, проходит через эффект. `UI` лежит выше, поэтому остаётся чётким.
Сцена рисуется в 960×720 (4:3) под пропорции картинки; окно открывается развёрнутым на весь экран, и картинка растягивается с сохранением пропорций.

## Как устроена «Улица» (`night_street.tscn`)
Ассеты — из пакета `references/US_1997_Night_Street_Godot` и спрайты полицейского из
`references/junior_officer_godot_pack`. Они копируются в `assets/night_street/` скриптом
`python3 tools/prepare_night_street.py`. Скрипт также перерисовывает голову фонаря, собирает
спрайт-лист полицейского (покой + 8 кадров ходьбы) и рисует текстуры для света.

```
NightStreet (scripts/night_street.gd — плавная пиксельная камера)
├─ Sky / DistantCity — небо и дальний силуэт со шпилем (0.1 / 0.23); в Sky — SkyFlash (вспышка молнии)
├─ CityMid / CityNear — кварталы справа за забором, собраны из модулей фасадов пакета (0.5 / 0.7)
├─ Lot              — дерево, старый седан и забор за участком (0.88)
├─ Facades, Sidewalk, Road — дома, тротуар, мокрый асфальт (вместе с миром)
├─ Lights           — пятна света на тротуаре (PointLight2D, мерцают)
├─ Glows            — свечение окон, лампы над дверью, витрины (glow_flicker.gd)
├─ World            — урна, будка, фонарь, полицейский (с тенями — hero_shadows.gd), машина
│  ├─ Flasher       — мигалка: красный/синий свет, заливка, блики на асфальте (police_lights.gd)
│  └─ Traffic       — раз в 18–35 с проезжает седан одной из 5 расцветок (без повторов подряд) с фарами и звуком
├─ StreetLampLight  — конус света и ореол фонаря
├─ LightHaze        — дымка из пакета
├─ Foreground       — тёмные размытые силуэты у камеры: крона, куст (1.35), столб со знаком (1.5)
├─ RainFar, Splashes / RainNear — дождь частицами за героем и перед ним, брызги на тротуаре и дороге (follow_camera.gd)
├─ RainSound, ThunderPlayer — петля дождя (loop_sound.gd) и гром после молнии
├─ WindowFlicker    — окно 2-го этажа слева иногда мигает и гаснет (window_flicker.gd, маска fx/window_off.png)
├─ Hints            — точки-подсказки (hint_point.gd): значок над объектом, по клику — субтитр
├─ UI               — значки, субтитр, список клавиш (street_ui.gd; H — скрыть), как в комнате
├─ LightningLight, Lightning — гроза: редкие вспышки освещают улицу и небо (lightning.gd)
└─ PostFX           — тот же шейдер, что в комнате
```
Звуки синтезируются скриптом `python3 tools/gen_street_sounds.py` в `assets/night_street/sfx/`:
дождь (петля), два варианта грома, машина (петля: шины по мокрому асфальту + мотор). Любой файл можно
заменить записанным звуком с тем же именем. Звук машины — `AudioStreamPlayer2D` на самой машине:
громкость и панорама по расстоянию, тон чуть выше при приближении и ниже после проезда.

Тени героя считаются от фонаря, лампы над дверью, витрины и мигалки: тень тянется от источника,
длина — по подобию треугольников, прозрачность падает с расстоянием, при выключенной фазе мигалки тень пропадает.
Слои выставлены так, что в правом конце улицы кадр совпадает с `reference_full_original.png`.

**Плавная пиксельная камера.** Мир всегда рендерится со сдвигом, кратным «большому» пикселю шейдера (3 px).
Остаток сдвига шейдер добавляет к готовой картинке (`scroll_frac`), а узор дизеринга едет вместе с миром (`dither_offset`).
Поэтому прокрутка плавная, а пиксели не «кипят». Для улицы в шейдере также включено усреднение по пикселю (`soften`), а дизеринг ослаблен до 0.5.

## Подставить свою графику в комнату
- Замените `assets/background.png` своей картинкой 960×720 (или поменяйте размер окна в Project Settings → Display → Window).
- Подвиньте иконки в `UI/Hotspots`.
- Параметры шейдера по умолчанию: Effect → Material → Shader Parameters.
- Лучше всего подставлять «чистый» рендер без пикселизации и без интерфейса: шейдер сам сделает пиксели и дизеринг.

Для настоящего пиксельного вида подключите пиксельный шрифт с кириллицей (Theme → Default Font).
